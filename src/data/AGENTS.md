# 검수된 사실과 배출 자료

현재 기본 통화는 preparation-guides.ts가 기존 quick 자료와 COACH_CATALOG에서 구성한 조건·행동 자료를 서버 지침으로 사용한다. coach-guides는 자료 원천 및 기존 단계별 소비자이며 기본 UI가 아니다.

품목별 사실 사전·질문·허용값, 출처, 조건별 배출 규칙을 소유한다. 실행 중 모델 호출·사용자 상태·HTTP 처리는 이 디렉터리에서 구현하지 않는다. 읽기 전용 자료이며 사용자 발화로 값을 덮어쓰지 않는다.

새 규칙은 공식 원문의 제품 조건·적용 지역·확인일을 확인하고 검수 상태와 부품별 출처를 함께 등록한다. 발행·수정일을 모르면 null로 남긴다. 출처를 확보하지 못했거나 자료가 충돌하면 활성 안내 대신 보류 조건으로 남긴다.

기존 상세 분석의 각 사실은 허용값과 unknown, 질문과 선택지, 사용자 확인 필요 여부를 가진다. 사진이 추가됐다는 이유로 사용자 확인이 필요한 사실의 성격을 바꾸지 않는다. 선택지 문구는 자유글 확인 검증에도 쓰이므로 문구 변경 시 정상 부정문·질문형·정정 사례를 확인한다.

품목의 대표 조건과 모든 변형을 구분한다. 식품용 EPS 충돌, 전분 아이스팩, 배달 잔여 국물·액체 기름, 미분리·복합 부속품을 근거 없이 기존 정상 규칙에 포함하지 않는다. 출처 URL을 나열하는 것만으로 해당 조건의 근거가 갖춰졌다고 판단하지 않는다.

변경 시 규칙·출처·사실 참조 유효성과 검수 상태를 검사하고 대표 성공과 인접 보류 조건을 함께 시험한다. 순서·부품·출처가 누락된 ready 결과가 나오면 자료를 고치며 테스트의 필수 조건을 낮추지 않는다.

기존 quick-guides 소비자는 배출 전 준비 방법을 제공한다. 검수된 ruleIds와 sources를 연결하고 적용 재질·상태를 scope와 부품 이름에 명시한다. 이미 관찰·확인한 사실처럼 표현하지 않는다. 아이스팩 성분·EPS 용도 선택 전에는 방법을 기본 선택하지 않는다.

기존 단계별 coach-guides와 coach-household-guides는 실물별 조건·행동·분기·부분 결과·검수 답을 구성한다. 원본 disposal-rules의 RULES/COACH_ADDITIONAL_RULES와 SOURCES에서 규칙·출처를 가져오며 별도 정답 사본을 만들지 않는다. 새 상품 이름 목록으로 인식 범위를 제한하지 않는다.

단계·선택·답 ID와 흐름 참조는 카탈로그 검증을 통과해야 한다. 답은 현재 단계에 허용된 선택만 제안하고 음성 문장도 검수한다. 관련 없는 일반 도움 한 문장으로 모든 질문을 대신하지 않는다. 공식 문의 범주는 안내 경로만 제공하며 예약·신고 완료를 뜻하지 않는다.

범주마다 대표 정상·인접 보류·불명 조건과 부품이 둘 이상인 경로를 검사한다. 준비된 부품 뒤 다른 부품을 보류하는 경우와 이전 선택 정정을 반드시 포함한다. 행동의 이유·적용 조건·운영 주체·확인일을 함께 관리한다.
