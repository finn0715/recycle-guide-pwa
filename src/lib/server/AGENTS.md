# 요청·모델·배출 기준 검증

서버 요청 해독, 외부 모델 호출, 관찰 검증, 정적 규칙 선택을 소유한다. 카탈로그 내용은 `src/data`, 공통 타입은 `src/lib/contracts`, 사용자 상태는 클라이언트의 책임이다. 기존 analyze/coach API는 모델이 만든 배출 문구나 출처를 결과로 통과시키지 않는다. 기본 실시간 통화의 생성 음성과 검증 한계는 아래 별도 절을 따른다.

본문은 스트림 크기 한도 안에서 읽고 실제 이미지 해독·MIME 일치·단일 프레임을 확인한다. 타임아웃과 취소 시 읽기·네이티브 해독·모델 요청을 정리하며 처리 슬롯을 중복 반환하거나 누수시키지 않는다. 잘못된 요청은 외부 모델에 보내기 전에 거절한다.

기존 상세 분석의 모델 관찰은 엄격한 스키마와 등록된 사실 키·값으로 검증한다. user 근거는 실제 발화 인덱스와 인용을 모두 대조한다. 질문·인용·명령을 사실 확인으로 승격하지 않고, 등록 선택지의 정상 부정문은 보존한다. 정정 이후 이전 사실을 재주입하지 않도록 최신 발화 위치와 제품 범위를 유지한다. 사진 허용 사실 외의 내부 상태는 사용자 확인 없이 확정하지 않는다.

규칙은 검수 상태·지역·조건·출처 참조를 확인한 뒤 선택한다. 기존 상세 분석에서 부족은 질문, 모름·상충·규칙 부재는 확정 안내 없는 종료다. 서버 키는 로컬 설정에서만 읽고 로그·응답에 넣지 않는다. 모델 저장·SDK 로그·자동 재시도를 활성화하지 않는다. 예상치 못한 오류도 원본 내용을 그대로 반환하지 않는다.

API 검사에서는 형식·크기·해상도·타임아웃·동시 처리·정리를 검증한다. 관찰 검사에서는 잘못된 사용자 인용, assistant 근거, 질문형, 혼합 정정, 오래된 사실을 포함한다. 규칙 변경에는 미검수 인접 조건과 출처 유효성을 함께 확인한다. 실제 모델 검증은 준비 입력임을 명시하고 사진·대화 본문과 키를 증거에 남기지 않는다.

기존 identify 경로는 여러 물체·여러 사진에서 지원 품목 ID만 반환한다. 내부 사실·배출 문구를 모델에 요구하지 않는다. 기존 요청 해독·취소·동시 처리 경계를 공유한다. 기존 analyze 경로의 상세 사실 검증과 구분하며 새로운 응답의 중복 ID·상태 모순도 거절한다.

coach 인식은 범주 후보·보이는 부품·정규화 위치만 받으며 서버가 실물·부품 ID를 부여한다. 사진 ID·부모 부품 참조·현재 범주 역할을 검사한다. 불명·범위 밖 관찰은 복구/공식 문의 흐름에 연결하고 같은 종류의 다른 실물을 합치지 않는다.

도움은 선택 이력을 재생해 현재 단계와 허용 답을 재구성한다. 음성은 공통 WAV 검증 후 한국어를 전사하고, 모델에는 허용 replyId와 정확한 choiceIds 선택만 맡긴다. 사용자 발화를 사실 패치나 진행 변경으로 바로 적용하지 않는다.

음성 출력은 서버가 선택한 speechText만 요청별 Realtime 연결로 전달한다. 출력 텍스트·응답 ID·콘텐츠 구조·PCM 크기를 검증한 뒤 WAV를 반환한다. 자유 생성 오디오를 검증 전에 브라우저로 흘려보내지 않는다. 완료·취소·오류 시 연결과 임시 PCM을 정리한다.

coach와 기존 API는 동일 프로세스의 요청 수용 한도를 공유한다. 취소·타임아웃 응답 이후에도 실제 네이티브/모델 작업이 끝나기 전 슬롯을 반환하지 않는다. 실제 검사에는 multipart·JSON·WAV, 현재 단계/카탈로그 불일치, 안전한 오류, 허용 문장 대조, 지연 완료와 슬롯 복구를 포함한다.

## 기본 실시간 통화

`recycling-call`은 검수 준비 자료를 서버 세션 지침에 넣고 `/v1/realtime/calls`로 SDP를 교환한다. 서버 키는 계속 서버에만 남는다. 브라우저에는 SDP와 메모리 기반 단기 종료 토큰을 보낸다. 동일 Origin/Host·SDP 크기·동시 통화 수를 검사한다. 자동 감지·끼어들기를 켜며 자유 대화 음성은 실시간으로 전달된다. 이 경로에는 기존 coach의 발화 전체 텍스트 일치 검증이 없으므로 같은 보장을 주장하지 않는다. 확인되지 않은 재질·성분은 질문/조건부 안내로 처리하도록 지침에 제한한다. 기본 통화는 최대 10분 뒤 종료하며 공개 배포 범위는 여전히 별도다.

기본 통화의 `X-Recycling-Language`는 ko/en만 허용하고 생략은 ko다. 선택 언어를 전사·세션 지침에 반영하되 송파구 검수 자료와 안전 조건은 동일하게 유지한다.
