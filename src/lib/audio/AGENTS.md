# 브라우저·서버 공통 WAV 처리

이 디렉터리의 WAV 검사는 기존 coach 녹음·음성 API용이다. 기본 RecyclingCallApp은 WebRTC 미디어 트랙을 사용하며 이 WAV 문장 대조 경로를 거치지 않는다.

RIFF/WAVE 해독·생성, PCM 길이·형식·무음 확인, 장치 샘플레이트에서 공통 입력 형식으로 변환하는 경계를 소유한다. HTTP·모델 호출·마이크 권한·AudioContext 수명은 소유하지 않는다. 브라우저 전용 객체나 서버 키를 가져오지 않는다.

파일명이나 MIME을 실제 PCM의 증거로 사용하지 않는다. 헤더 길이, fmt/data 청크 중복·범위, 채널·레이트·비트·정렬·실제 샘플 수를 확인한다. 잘린 파일·무음·비유한 샘플·20초/1MiB 초과를 유효 음성으로 통과시키지 않는다. 브라우저와 서버에서 같은 제한을 사용한다.

해독 결과는 호출자가 사용 후 정리할 수 있는 PCM이다. 원본과 임시 버퍼를 파일·로그로 쓰지 않는다. 리샘플링은 실제 장치 레이트를 사용하고 한 하드웨어 레이트로 고정하지 않는다. 검사에는 잘못된 청크·음량·경계 길이·리샘플링과 브라우저/서버 전송 양쪽의 WAV 해독을 포함한다.
