# 분리배출 화면

사진 강조·동작 도해·현재 선택·도움 답·부품별 결과·행동 근거를 한국어로 표시하고 조작을 제어기에 전달한다. HTTP·사진 해독·마이크 수명은 클라이언트 어댑터에 맡긴다. 모델·공식 규칙·출처 원본은 여기서 작성하지 않는다.

기본 화면은 RecyclingCallApp이다. 첫 화면은 말로 물어보기를 가장 먼저 강조하고 사진 입력 두 버튼을 별도 영역으로 묶는다. 후면 카메라 촬영 입력(`capture=environment`), 별도 앨범 선택, 사진 없이 말로 물어보기 진입을 둔다. 한국어·영어는 시작 전에 선택하고 연결 중·안내 중에는 전환을 잠근다. 화면·오류·음성 언어를 일치시키되 언어로 지역 기준을 바꾸지 않는다. 사진 선택은 기존 음성 연결 뒤 자동 전송하며 연결 취소·오류 때 대기 사진을 폐기한다. 지역은 실제 지원하는 송파구만 표시한다. 통화 중 마이크·카메라·사진·종료를 제공하고 질문마다 시작·보내기·완료 입력을 요구하지 않는다. 마이크는 통화 시작에서, 실시간 카메라 스트림은 통화 중 카메라 켜기에서만 요청한다. 첫 화면 촬영은 별도 네이티브 파일 입력이다. 카메라 실패로 음성 통화를 종료하지 않는다. 음성 자막은 최근 답만 유지한다. 아래 PhotoRecyclingCoach는 이전 소비자의 경계다. 촬영/사진 선택을 중심에 두며 직접 품목 찾기·품목 목록·이름 검색 폼은 표시하지 않는다. 인식 정정은 사진 재촬영·추가 사진으로 한다. 처리·비보관·AI 음성 안내는 정보 메뉴에 두고 사진 개수 제한은 초과 입력 때 알린다. 품목 인식 뒤 검수된 준비 방법과 조건별 버릴 곳을 바로 표시한다. 체크·완료 입력은 요구하지 않으며 준비 방법을 확인된 사실이나 완료 결과로 표시하지 않는다. 성분·용도에 따라 결과가 달라지는 아이스팩·EPS는 선택 전 방법을 확정하지 않는다. 단계별 확인·음성은 선택한 보조 경로이며 사진 없는 경로는 수동 선택임을 표시한다. 기존 QuickRecyclingGuide/RecyclingGuide의 동작을 새 기본 화면으로 혼동하지 않는다.

사진 전체 방향·비율을 보존하고 실제 이미지 표시 영역에 맞춰 정규화 좌표를 옮긴다. 확인되지 않은 부품 영역을 임의로 표시하지 않는다. 도해는 현재 부품의 동작을 설명하며 무관한 아이콘 목록으로 대체하지 않는다. 사용자에게 필요한 현재 주의는 접지 않는다.

화면에서 별도 완료를 만들지 않는다. 부분 결과는 준비된 부품과 보류 부품을 함께 보여 주고 각 부품이 도달한 단계의 이유·출처에 연결한다. 보류 화면을 닫기 전에도 이미 준비한 부품을 숨기지 않는다. 없는 부품에는 가상의 목적지를 표시하지 않는다.

음성 시작/중단/질문은 제어기에 위임하고 사용자 제스처에서 재생을 준비한다. 음소거로 도움 답을 지우지 않는다. 비보안 LAN HTTP·권한 거절·음성 오류에는 글·버튼 대안을 보여 준다. 질문 길이 초과는 입력을 보존하고 오류를 알리며 maxlength로 잘라내지 않는다.

부품 분류는 색과 글을 함께 사용한다. 터치 영역·키보드 포커스·글자 확대·동작 줄이기와 가로 화면을 유지한다. 테스트에서는 사진·정정·모름·부분 보류·근거·재시작·중복 동작을 검사한다. Aside는 매 행동 뒤 스냅샷과 필요한 캡처로 확인하고 데스크톱 CSS 폭과 실물 카메라·가상 키보드는 구분해 기록한다.
