## Project Name

RecycleGuide

## Project Description

RecycleGuide is a Korean- and English-language web prototype that helps people ask how to prepare everyday waste for disposal in Songpa-gu. Users choose a language and ask by voice, or start with a camera photo or uploaded image. They can also share images during the conversation, without searching an item list or checking off every action. Both languages use the same Songpa-gu guidance.

The application supplies reviewed local guidance to a real-time AI model, which gives short spoken responses. Instructions tell it to ask a necessary question when material or contents are unclear and to avoid definite classifications when guidance conflicts. Camera sharing sends periodic still images, rather than continuous video.

Automated checks and browser trials with synthetic Korean speech and test images confirmed connection, responses, interruption, image sharing, and call cleanup. These trials do not establish real-world disposal accuracy. Physical phone use, human listening quality, and environmental benefits remain unverified. Generated advice can be wrong, even when reviewed guidance is provided.

## AI Usage Explanation

RecycleGuide uses OpenAI gpt-realtime-2.1-mini for real-time voice conversation and image understanding, with gpt-transcribe for Korean or English input transcription. The browser exchanges audio through WebRTC. A server supplies reviewed preparation guidance and keeps the API key out of the browser. The application does not persist user audio, images, or conversation history; this does not imply that the external provider has no processing or retention.

The model generates short replies from the supplied guidance. Unlike an earlier step-based prototype, the current voice flow does not check every generated sentence against an approved sentence before playback. Instructions cover uncertain materials, unidentified ice-pack contents, conflicting foam-packaging guidance, and hazardous items, but their reliability still needs testing with real objects.
