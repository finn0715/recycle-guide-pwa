# 발표용 설명과 적용 원칙

작성일: 2026-10-01. 아래는 최초 설계 기록이다. 현재 구현한 송파구 10종 조건부 규칙과 범위는 [구현규칙과검증](04_구현규칙과검증.md)을 기준으로 설명한다.

## 발표에서 설명할 핵심

> 이 프로젝트는 복잡한 분리배출 정보를 실제 행동으로 옮기도록 돕는 서비스입니다. 사진과 사용자의 설명으로 물건의 종류와 상태를 파악하고, 부족한 정보는 질문합니다. 공식 품목별 안내와 적용 지역의 기준을 근거로 지금 해야 할 처리 방법을 알려주는 구조를 설계했습니다.

현재 확보한 자료: ‘분리의 정석’의 운영 소개 및 린스 품목 안내, 송파구의 재활용품 배출 안내. 2026 Q&A 사례집은 발간 정보만 확인했다. 최초 조사 당시 지역은 미정이었으나, 현재 구현 범위는 송파구 가정 배출이다.

## AI와 자료의 역할

1. AI: 사진·음성·글에서 물건, 부속품, 사용자가 설명한 상태를 파악한다.
2. 확인 질문: 사진에 보이지 않는 정보나 애매한 재질을 보완한다.
3. 기준 연결: 확인된 조건과 지역에 맞는 검수된 안내를 선택한다.
4. 결과: 처리 순서, 배출 분류, 근거를 전달한다.

이 구조의 구현 범위와 검증 결과는 별도 구현 기록을 따른다. 공식 기관이 우리 AI의 정확성을 보증하거나 공동 개발한 것처럼 설명하지 않는다. 기존 안내 사이트와 차별화하려는 지점은 사진·설명으로 상황을 이해하고 필요한 행동을 쉽게 전달하는 사용자 경험이다.

## 자료를 서비스에 넣을 때 보존할 항목

품목 / 재질·상태 조건 / 확인 질문 / 처리 순서 / 배출 분류 / 적용 지역 / 출처 URL과 해당 항목 / 자료 발행·수정일(미확인 가능) / 확인일 / 검수 상태.

지역·발행시점·주택 유형 등 조건이 다른 자료를 무조건 합치지 않는다. 충돌 시 적용 범위를 확인하고, 해결되지 않으면 담당 기관 확인 전까지 정답으로 사용하지 않는다.

## 다음에 확인할 것

- 실제 시험할 지역과 주거 형태를 정한다.
- 초기 품목을 3~5개 선정하고 각각의 공식 근거와 예외를 검수한다.
- 음식물·일반쓰레기 경계 사례를 사용하려면 해당 지자체의 음식물 배출 기준을 추가 확보한다.
- 자료 변경 여부는 시연·배포 전에 다시 확인한다.
- 같은 사례에서 기존 안내문과 서비스 사용 시 처리 방법 선택의 정확도·소요 시간을 비교한다. 아직 측정 결과는 없다.

환경 효과는 기대와 측정 결과를 구분한다. 처리 안내의 정확도가 개선되어도 실제 재활용률이나 탄소배출량이 개선됐다고 자동으로 주장하지 않는다.
