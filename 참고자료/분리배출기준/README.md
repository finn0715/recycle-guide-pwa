# 분리배출 안내 근거 자료

2026-10-08 구현 연결: 이 자료의 검수 조건을 현재 통화형 안내의 서버 지침에 사용한다. 아래 조사 확인일은 그대로이며 이번 문서 정리는 공식 기준의 재확인이 아니다. 04~06의 단계·선택·검수 음성 설계는 기존 coach 이력이고 현재 기본 UX는 [결정 0006](../../docs/tracking/decisions/0006-conversation-first.md)을 따른다.

확인일: 2026-10-01 (한국시간)

공식 웹페이지를 직접 확인해 프로젝트용으로 재구성한 조사 자료다. 원문 전문이나 PDF 복제본이 아니라 출처, 확인한 사실, 적용 조건을 보존한 요약이다. 서비스 구현 및 성능 검증 완료를 의미하지 않는다.

## 기준 선택

기본 참고 자료는 기후에너지환경부의 생활폐기물 분리배출 누리집 ‘분리의 정석’이다. 품목별 안내에 더해 적용 지역의 지자체 안내를 확인한다. ‘내 손안의 분리배출’ Q&A 사례집은 보완 자료로 둔다.

초기에는 송파구를 예시로 조사했고, 현재 앱의 적용 지역은 송파구로 고정했다. 학생의 거주 지역을 뜻하지 않는다. 다른 지역에 송파구 기준을 자동 적용하지 않는다.

공식 자료끼리 충돌하거나 해당 상황의 근거가 없으면 확인 필요로 남긴다. 출처의 확인일과 발행일은 서로 구분하며, 확인일이 최신 개정일을 의미하지 않는다.
