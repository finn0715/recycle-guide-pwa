확인일: **2026-10-08**. 적용 지역: **송파구**. 카탈로그: `songpa-coach-2026-10-08-v3`.

상품명이 아닌 재질·용도·부품과 사용자의 준비 응답으로 진행한다. 모델의 관찰은 아래 조건의 확인을 대신하지 않는다. 완료는 사용자가 준비했다고 보고한 상태이며 AI의 실물 인증이나 수거 후 재활용 보장이 아니다. 질문 도움은 허용된 답과 선택지만 제시하며 사실을 자동 적용하지 않는다.

부품은 앞선 준비 결과를 유지한다. 예: 상자 테이프 분리·종량제 준비 후 송장 제거 실패 시 테이프만 일반쓰레기 결과를 유지하고 본체·송장은 보류한다. 앞선 선택을 정정하면 이후 부품 결과는 이력 재생으로 폐기한다. 없음으로 답한 부품은 보류 화면에도 만들지 않는다.

## 도해와 도움

`ActionDiagram`은 칫솔, 고철 공구, 골판지 상자, EPS 상자, 종이, 팩, 유리병, 아이스팩, 전지·전자제품·가구·위험 용기의 외형을 각각 그린다. 도해는 예시이며 실제 사진의 보이지 않는 부품·내용물 관찰이 아니다.

- `water-pack-empty`: **물100% 확인 후에만** 물 비움 예시. 기존 `empty`는 다 사용한 용기의 안쪽 확인 그대로 유지.
- `carton-dry`: 헹군 팩의 물기 제거·건조. 가열을 제시하지 않음.
- `paper-stack`: 마른 종이를 펴서 쌓고 묶기. 상자 펼치기는 골판지 날개를 펼친 모습.
- 각 행동의 `-help`는 현재 방법, `-cannot`은 해당 장애와 관련 선택, `-why`는 재질·처리 이유, 흐름별 `-scope-help`는 다른 물건 질문의 범위를 안내한다. 질문만으로 선택·완료가 적용되지 않는다.

공통 계약과 기존 10종 API enum·규칙 조건은 변경하지 않았다. 신규 범주도 동일 카탈로그·이력 검증·부품 보존 경계를 사용한다.

### 부품별 준비 사실과 없음 응답

플라스틱 뚜껑·필름과 종이팩 빨대·비닐은 원본 부품 규칙의 출처를 공유하는 `coach-*-prepared` 규칙을 `disposal-rules.ts`에 둔다. 각 부품의 **재질 + 분리 완료 + 세척 완료**를 모두 요구한다. 기존 10종 `RULES`의 aggregate 조건은 완화하지 않는다. 재질 선택만으로 `clean_*`를 기록하지 않으며, 본체에 필요한 aggregate는 모든 해당 부품 준비 뒤에 기록한다.

두 부품이 있으면 첫 부품 세척→첫 부품 destination→다음 부품 분리 순서다. 다음 부품이 안 떨어져도 이미 준비한 첫 부품은 유지한다. 정정으로 분리·세척 근거가 사라지면 그 결과는 폐기한다. 각 개별 조건 하나를 지운 변형에서 서버 계약 검증이 거부하는 회귀검사를 포함했다.

새 비움 행동은 사용자가 직접 고른 ‘남은 내용물이 없어요’, 세척은 ‘이물질이 없어요’로 같은 다음 단계와 준비 사실을 기록한다. 펼치기·묶기·건조·이미 존재가 확인된 부품 분리에는 뜻이 맞지 않는 ‘없어요’를 표시하지 않는다.
