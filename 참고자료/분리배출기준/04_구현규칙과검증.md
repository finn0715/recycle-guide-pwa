# 송파구 10종 구현 규칙과 검증

적용 범위: 기존 상세/단계별 소비자의 기준과 검수 이력이다. 현재 기본 화면은 통화형이며 생성 발화의 검증 경계가 다르다. [현재 아키텍처](../../docs/architecture.md)를 먼저 확인한다. 아래 조사·조건·당시 검증 기록은 보존한다.

확인일: 2026-10-01. 송파구 가정 배출을 대상으로 한다. 공식 원문을 토대로 프로젝트에서 조건을 나누고 문구를 작성했다. 기관이 이 서비스나 개별 판정을 검수·보증한 것은 아니다.

## 구현 경계

- `src/data/facts.ts`: 품목별 허용 사실, 값, 질문·선택지, 사진 허용 여부.
- `src/data/disposal-rules.ts`: 조건부 규칙 28개, 출처 레지스트리 22개. 각 출처에 URL·확인일·본문 절·발행일 또는 null·지역 범위를 보존한다.
- `src/lib/server/rules.ts`: 검증·필요 질문 선택·고정 문구 조합. AI가 만든 배출 지시나 출처를 입력받지 않는다.
- `tests/rules/`: 10종 대표 정답, 최대 질문 수, 분기, 확인 불가, 사진의 한계, 위조된 사실·출처를 검증한다.

규칙의 `reviewStatus: reviewed`는 위 공식 원문과 대조한 구현 검수를 의미한다. 전국 안내를 송파구 자체 규정으로 표시하지 않는다. 구청 안내가 있으면 이를 우선한다. 일회성 수거 사업의 과거 일정을 현재 일정으로 사용하지 않는다.

## 호출 인터페이스

```ts
import { FACT_REGISTRY, validateFacts, resolveRules } from "@/lib/server/rules";

const facts = validateFacts("pump_bottle", {
  material: "plastic", contents: "empty", pump: "composite", label: "film",
});
const result = resolveRules("pump_bottle", facts, {
  confirmedFactKeys: ["material", "contents", "pump", "label"],
});
```

`result`는 공통 API 계약의 `status`, `question`, `guidance`, `message`만 반환한다. API는 `requestId`와 `item`을 추가한다. `FACT_REGISTRY[itemId][key].choices`는 내부 값→한국어 선택지 매핑이다. 질문 문구도 레지스트리에서 가져온다.

`validateFacts(itemId, raw)`는 item별 `Record<string,string>`만 허용한다. 다른 품목의 key, 잘못된 값, 임의 안내·출처는 `InvalidFactsError`로 거부한다. `resolveRules`에서도 다시 검증한다. 누락 key와 `unknown`은 미확인 상태다.

`confirmedFactKeys`는 서버가 실제 사용자 발화로 확인한 key만 전달한다. 모델이 스스로 “사용자 확인”이라고 한 결과를 그대로 신뢰하면 안 된다. 사진 관찰만으로 내부 잔여물, 세척 가능 여부, 펌프 내부 스프링, 냉매 성분을 확인하지 않는다. 기본 확인 key 목록은 비어 있다. 사진만으로 확정할 수 있는 photo_allowed fact는 명확히 보이는 PET 뚜껑 유무, 유리병 깨짐, 아이스팩 누출 여부뿐이다. 모든 후속 질문은 question.allowPhoto=true로 같은 제품의 라벨·재질 표시 등 보조사진 첨부를 허용한다. 사진 첨부 허용은 사실 확정 권한과 별개이며, user_only 재질·라벨·냉매·내부 상태는 보조사진을 추가해도 실제 사용자 확인 전까지 미확인으로 유지한다.

사용자가 “확인하기 어려워요”라고 답하면 해당 key를 `unableToAnswer`에 전달한다. 처음부터 `unknown`인 것과 구분하여 추가 질문을 반복하지 않고 `uncertain`으로 끝낸다. 해결되지 않은 조건, 미검수 재질, 규칙 충돌도 `uncertain`, `question: null`, `guidance: null`이다. 일부 부품만 알아도 전체가 확정된 것처럼 안내하지 않는다.

후보 규칙에 필요한 fact만 질문하므로 젤 아이스팩에는 포장재를 묻지 않으며, 빈 배달 용기에는 남은 음식 종류를 묻지 않는다. 대표 사례는 최대 5회 질문(스티로폼), 다른 9종은 최대 4회로 완료한다. 부속품의 유무·검수 재질·분리·청결 상태를 한 질문에서 선택하므로 빈 배달 용기에 남은 음식 질문을 덧붙이지 않는다. 질문과 답을 합해 최대 10개 메시지로 대표 결과에 도달한다.

## 전분형 아이스팩 추가 확인과 보류

2026-10-01 환경부 카드뉴스 [친환경 아이스팩 사용으로 환경을 지켜주세요!](https://mcee.go.kr/home/web/board/read.do?boardId=1454460&boardMasterId=713&menuId=10392)의 원문 HTTP 200과 이미지 대체텍스트를 확인했다. 발행일은 2021-05-24이며, 확인 범위는 '아이스팩 사용 실태' 절이다. 웹 도구 직접 열기는 실패해 원문 HTTPS로 확인했다.

이 자료는 물과 전분·소금을 섞은 냉매가 사용된다는 **소재 구분의 근거**다. 전분형의 내용물·포장재를 송파구에서 어떻게 배출하는지 정하는 근거로는 사용하지 않는다. 기존 국가 품목사전은 물 아이스팩과 고흡수성수지(SAP) 젤 아이스팩을 다루며 전분 혼합물의 배출방법을 확인해 주지 않는다. '친환경' 표시나 젤 같은 외관만으로 물 100% 또는 SAP라고 판단하지 않는다.

레지스트리는 water=물 100% 표시, gel=SAP 표시, starch=전분 또는 전분 혼합 표시, other=그 외, unknown=확인 불가를 별도로 둔다. 냉매는 모두 user_only 확인이다. starch에는 배출 규칙을 만들지 않았으므로 포장이 온전하거나 비닐임을 알아도 uncertain으로 끝난다. 물의 하수구 배출과 SAP 젤의 포장째 종량제 배출을 전분에 확대하지 않는다. 사용자에게 성분과 처리 방법을 제품 제조사 또는 송파구청에 확인하도록 안내한다.

이 배경 자료는 실제 배출 정답에 사용하는 출처 레지스트리에 포함하지 않았다. 전분형의 배출 근거와 검수가 확보되기 전에는 정답 규칙을 추가하지 않는다.

### 후속 질문 보조사진 보완

- `question.allowPhoto`는 사진 첨부 가능 여부, `evidence`는 사진만으로 사실을 확정할 수 있는지 여부다. 두 권한을 분리했다.

### 스티로폼 충돌을 보류한 이유

- [송파 현행 본문](https://www.songpa.go.kr/www/contents.do?key=3164)의 스티로폼 완충재 절은 농·수·축산물 포장용 발포스티렌 상자를 해당 품목으로 제시하고 세척·이물질 제거를 안내한다. 색상 제한은 본문에서 확인되지 않는다.
- 연결 안내서 인쇄 10쪽은 흰색 스티로폼 박스·완충재라는 제목 아래 식품 포장용은 종량제라는 주석을 둔다. 이미지상 이 문구는 컵라면·트레이·오염에 한정되어 있지 않다. 따라서 식품 배송 상자까지 적용되는지 해석이 충돌한다.
- 현행 국가 사전의 유색 스티로폼 안내가 있더라도 송파 안내서의 흰색 범위를 임의로 넓히지 않는다. colored에는 재활용·종량제 어느 쪽 정답도 만들지 않았다.
- 활성 범위는 흰색 비식품 생활용품 배송 EPS 상자이며 건축재와 전자제품 포장재도 제외한다. 식품용에는 두 송파 자료의 차이를 안내하고 uncertain을 반환한다. 일반 EPS 재질만 확인한 과거 입력은 용도·색상·부속품 질문 전까지 ready가 되지 않는다.

### 추가 fact 계약

모두 `user_only`, `question.allowPhoto=true`이며 아래 값에 `unknown`이 공통으로 추가된다. 기존 fact의 key/value를 삭제하지 않았다. `none`은 화면에 안 보인다는 추측이 아니라 사용자 확인이다. listed 조건에 맞지 않는 부속품이 하나라도 있으면 other로 처리한다.

| 품목.key | 값 |
|---|---|
| drink_carton.accessories | none, clean_pp_straw, clean_film, clean_pp_straw_and_film, other |
| cardboard_box.attachments / foam_box.attachments | none, tape, shipping_label, tape_and_label, other |
| takeaway_container.cover | none, clean_film, clean_plastic_lid, clean_lid_and_film, other |
| foam_box.color | white, colored |
| foam_box.packaging_use | non_food, food, other |

배달 용기의 clean_lid_and_film은 뚜껑 PET·PE·PP·PS, 필름 PP·PE를 모두 확인해야 한다. 알루미늄·종이 복합 밀봉 필름, 재질 불명, 떼어지지 않음, 오염은 other다. 용기 본체의 잔여 음식 분기나 제거 불가능 오염 분기에도 cover 확인은 생략하지 않는다. 확인 불가 답은 반복 질문 없이 uncertain으로 종료한다. 전체 부품을 확인하기 전에 generic 주의 문구만 붙여 ready로 끝내지 않는다.
