# 분리배출 판단 기준

## 현재 통화형 기본 흐름

사용자가 말로 물어보기를 누르거나 촬영·앨범 사진을 선택해 연결하면 음성으로 묻고 답하며, 필요할 때 카메라·사진으로 현재 물건을 보여준다. 한국어·영어는 시작 전에 선택하며 두 언어 모두 송파구 기준을 따른다. 품목 찾기·완료 체크는 기본 흐름에 없다. 검수 자료의 적용 조건을 유지하면서 모델이 짧은 답을 생성한다. 불명 성분·재질은 한 가지 핵심 질문 또는 조건부 안내로 다루며 사용자의 정정을 반영한다. 이 대화는 아래 기존 단계별 사실 이력과 별도이며, 실시간 발화에 문장 일치 검증을 적용한 것으로 주장하지 않는다.

기본 통화에는 체크로 확정하는 완료 상태가 없다. 기존 단계별 소비자에서 서비스의 완료는 사용자가 부품별 배출 준비를 마쳤다고 보고한 상태다. AI가 실물을 검증하거나 수거·재활용 성공을 인증한 것이 아니다. 적용 지역은 송파구이며 국가 자료는 해당 재질·용도·조건에 맞는 근거로 사용한다. 배출요일·장소를 사용자 위치에서 추정하지 않는다.

## 이전 coach의 사진과 실물·부품

사진 1~3장에 나타난 실물별로 안내한다. 같은 종류의 캔 두 개는 서로 다른 물건이며 답·진행·부품을 섞지 않는다. 여러 사진이 같은 실물인지 불명확하면 별도 후보로 보여 주고 현재 물건을 사용자가 선택한다. 상품명이나 브랜드가 낯설어도 재질·용도·부품의 검수 조건을 찾으며 이름 목록 밖이라는 이유만으로 종료하지 않는다.

현재 행동의 물건·부품을 내 사진에서 짚고, 떼기·비우기·헹구기·펼치기 등의 동작을 도해로 보인다. 위치를 확인할 수 없으면 표시를 억지로 만들지 않고 영역 확인·부품이 보이는 추가 사진·물건 설명 정정으로 이어간다. 보이지 않는 펌프 내부를 사진에서 확인했다고 말하지 않는다. 사진 없는 직접 선택에는 예시임을 표시한다.

## 이전 coach의 단계별 준비와 보류

물건 확인 → 필요한 조건 확인 → 현재 행동 → 했음/문제/모름 선택 → 다음 행동 → 부품별 버리는 곳 순서로 진행한다. 한 화면의 주 행동은 하나이며, 필요한 주의는 접지 않는다. 정확한 재질·용도·비움·세척·냉매 성분은 사용자가 버튼으로 확인한다. 발화나 추가 사진만으로 숨은 상태·완료를 확정하지 않는다.

‘안돼요’에는 현재 행동의 검수된 대안과 관련 선택지를 제시한다. 근거 없이 힘주기·찌르기·가열하기를 만들지 않는다. 해결하지 못한 부품은 보류하며 이미 준비한 다른 부품의 결과는 유지한다. 하나라도 보류하면 전체 준비 완료로 표시하지 않는다. ‘없어요’로 보고한 부품에 가상의 목적지를 추가하지 않는다.

이전 선택을 바꾸면 그 답에 의존한 후속 선택·목적지·완료를 무효화한다. 같은 사진 묶음의 물건 전환에서는 각각의 진행을 유지하되 이전 물건의 재생은 끊는다. 새 사진으로 다시 인식하면 이전 관찰·진행을 자동 이전하지 않는다. 새로 시작은 사진·진행·질문·음성을 비운다. 실패를 완료로 바꾸지 않고 유효한 입력과 진행에서 수동 재시도한다.

## 일상 안내와 공식 문의 범위

| 범주 | 검수 조건과 보류 경계 |
|---|---|
| 음료·식품 금속캔 | 알루미늄 음료캔·철 식품캔을 구분하고 비움·이물질·다른 재질 부품을 확인한다. 가스·스프레이에 일반 캔 동작을 적용하지 않는다. |
| 고철·금속 물건 | 전기제품이 아닌 단일 금속과 이물질 없는 조건을 확인한다. 복합 재질·날카로워 준비하기 어려운 물건은 보류한다. |
| 플라스틱 펌프 용기 | 본체·복합 펌프·비닐 라벨을 따로 확인한다. 단일재질 펌프·불명 구조·미분리 부품에 대표 분류를 강제하지 않는다. |
| 투명 음료 PET | 투명 생수·음료용 조건, 라벨·비움·이물질을 확인한다. 뚜껑이 있으면 다시 닫는 검수 기준을 사용하며 없는 뚜껑을 새로 요구하지 않는다. |
| 일반 플라스틱 용기 | PET·PE·PP·PS 본체와 확인한 뚜껑·필름을 각각 준비한다. 남은 국물·기름·미확인 복합 필름을 빈 용기 조건에 포함하지 않는다. |
| 식품·음료 유리병 | 일반 병·금속 뚜껑·보증금·파손 여부를 구분한다. 내열유리·복합 뚜껑을 일반 병으로 확정하지 않는다. |
| 종이·신문·책 | 마른 비코팅 종이와 다른 재질 부품을 확인한다. 코팅·오염·복합 재질은 대표 종이 규칙으로 메우지 않는다. |
| 골판지 상자 | 깨끗하고 마른 골판지, 분리 가능한 테이프·송장을 각각 준비한다. 젖음·기름·코팅·제거 불가 부속품은 보류한다. |
| 우유·두유·음료팩 | 일반팩·멸균팩을 구분하고 부속품·비움·세척·건조를 확인한다. 단일 PP 빨대·PP/PE 포장만 해당 부품 규칙에 연결한다. |
| 비닐 포장재 | 빈 깨끗한 비닐 조건을 확인한다. 남은 내용물·제거 불가 오염을 사진만으로 없다고 보지 않는다. |
| EPS 포장재 | 검수된 흰색 비코팅 비식품 생활용품 배송 조건만 확정한다. 식품 포장 원문 충돌·유색·코팅·전자제품·건축재는 보류한다. |
| 칫솔 | 배터리 없는 일반 플라스틱 수동 칫솔만 대표 규칙을 적용한다. 전동·나무 제품을 같은 분류로 처리하지 않는다. |
| 아이스팩 | 직접 확인한 물 100%·SAP와 누출·포장을 구분한다. 물 100%만 확인된 방법으로 비울 수 있고 SAP·전분·불명 냉매는 임의로 붓지 않는다. |

배터리·전자제품·대형폐기물·가스/위험 내용물은 별도의 공식 수거·문의 4범주다. 관련 원문 경로를 보여 주되 앱이 예약·신고·통화를 완료한 것으로 표시하지 않는다. 분해·천공·가열을 유도하지 않는다. 카테고리도 불명확하면 재질 표시·선명한 추가 사진·직접 설명으로 확인하고, 근거 부재나 충돌이 남으면 안전한 보류 행동과 공식 확인 경로를 준다.

## 이전 기본 준비 안내

사진 인식 또는 직접 품목 선택 뒤 체크 없이 준비 방법을 바로 표시한다. `preparation-guides`는 기존 `quick-guides`의 검수된 준비 방법과 coach 카탈로그의 행동·출처를 재사용한다. 적용 조건과 예외를 함께 표시하며, 상태 확인이나 완료 보고로 저장하지 않는다. 아이스팩 성분·EPS 용도는 기본 선택하지 않는다. 사용자가 단계별 도움을 요청한 경우에만 아래 확인·음성 흐름을 시작한다.

## 음성과 근거

안내 시작은 현재 단계의 짧은 AI 음성을 재생하고 화면을 함께 강조한다. 음성은 보조이며 글·버튼으로 동일한 흐름을 진행할 수 있다. 녹음은 ‘말로 질문’에서 시작해 ‘말 마치기’에서 전송하고 취소하면 보내지 않는다. 녹음 시작은 현재 안내 재생을 멈춘다. 음소거는 현재 탭에서 유지하고 다시 켜거나 다시 들으면 현재 단계만 읽는다.

질문은 현재 단계와 앞선 선택에 연결하며 검수된 답과 선택지를 제안한다. 전사를 수정할 수 있지만 질문만으로 선택을 대신 적용하지 않는다. 권한 거절·무음·음성 처리 실패에서도 현재 단계는 유지한다.

각 행동·부품 분류에는 이유, 적용 조건, 발행 기관/운영 주체, 확인일, 원문을 제공한다. 확인일을 발행일로 쓰거나 비정부 운영 자료를 정부 발표처럼 표현하지 않는다. 새 조건은 공식 원문을 확인한 뒤 활성화하며 식품용 EPS 충돌과 미확인 냉매 보류를 새 근거 없이 제거하지 않는다.

## 상세 확인 API의 사실과 기준

최종 안내는 `품목 + 확인된 상태 + 해당 지역의 검수 조건`이 모두 맞을 때만 성립한다. 제품명만 맞거나 사진에서 재활용 표시가 보인다는 이유로 결과를 확정하지 않는다. 사실의 미확인은 부재·깨끗함·단일재질과 다르다.

재질, 내부 잔여물, 세척 후 상태, 펌프 내부 구조, 아이스팩 성분은 사용자 확인이 필요하다. 사진으로 허용하는 사실은 투명 PET의 뚜껑 존재, 식품 유리병의 파손 여부, 아이스팩의 누출 여부뿐이다. 사용자가 확인할 수 없다고 하면 추정으로 대체하지 않는다. 추가 사진은 정보를 보완하지만 내부 사실에 대한 사용자 확인을 대신하지 않는다.

사용자 질문·인용·명령은 상태를 보고한 답이 아니다. “다 비웠나요?”를 “다 비웠다”로 적용하지 않는다. 정정한 답보다 앞선 사실을 다시 끌어와 안내를 완성하지 않는다. 사진과 설명이 충돌하면 다시 확인하고, 제품군이 바뀌면 이전 제품의 답과 결과를 폐기한다.

배출 기준은 확인일·적용 조건·공식 출처를 가진 검수 자료에서만 가져온다. 송파구의 별도 조건을 먼저 확인하고 국가 안내는 해당 조건의 근거로 사용한다. 서로 다른 지역·시점·제품 조건을 합쳐 새 정답을 만들지 않는다. 확인일은 발행일이나 수정일과 다르며 모르는 날짜는 만들지 않는다.

## 상세 확인 API의 상태와 종료

사진 선택 전 → 사진 미리보기 → 분석 중 → 추가 질문 / 최종 안내 / 확인 불가 / 미지원 순서로 진행한다. 추가 질문에는 선택지·자유글·같은 제품 사진을 제출할 수 있다. 한 번에 기준 선택에 필요한 질문 하나를 제시한다.

- 필요한 확인이 빠졌으면 추가 질문을 한다. 여러 제품이나 흐린 사진이면 한 제품을 선명하게 다시 촬영하도록 요청한다.
- 지원 품목이고 조건·근거가 충족됐을 때만 최종 안내를 표시한다. 행동 순서, 부품별 분류, 주의점, 송파구 표시, 공식 출처와 확인일이 함께 있어야 한다.
- 확인할 수 없거나 미검수 조건·근거 충돌이면 확인 불가로 끝낸다. 확인할 표시와 공식 문의 경로를 주되 배출 정답을 붙이지 않는다.
- 10종 밖의 품목은 미지원으로 끝낸다. 비슷한 품목으로 강제 분류하지 않는다.
- 통신·분석 실패는 오류다. 확정 결과로 바꾸지 않고 사진과 입력을 유지해 수동 재시도한다.

물건 설명 수정은 사진만 남기고 기존 답·안내를 버린다. 다음 물건은 사진까지 비운다. 분석 중 이중 제출과 초기화 후 늦은 응답의 반영은 허용하지 않는다. 새로고침이나 다른 탭에서 이전 제품을 복원하지 않는다.
