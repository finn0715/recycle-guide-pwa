다음은 실제 기기의 신뢰된 HTTPS·권한·스피커·끼어들기·잠금/복귀 검증, 실제 물건의 짧은 안내 품질 확인이다. 생성 발화는 검수 자료를 지침으로 사용하며 문장 일치 검사로 확정된 정답이 아니다. 식품용 EPS 충돌과 불명 냉매를 추정으로 메우지 않는다.

현장 정확도·환경 효과·학생 직접 작업·최종 제출은 미확인이다. 전화번호 연결, 다른 지역·PWA·회원·DB·공개 배포는 구현 범위 밖이다. 상세 근거는 [verification](../verification.md), 미해결 범위는 [findings](findings.md)를 따른다.
