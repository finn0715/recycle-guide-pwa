**Sites PWA 현재 운영:** 설치·배포 소스, 접근 범위, Workers 통화 종료 계약과 검증은 [Sites PWA](../sites-pwa.md)를 우선 따른다. 아래 Next 로컬 서버 기록과 구분한다.

기준일: 2026-10-08. 이 문서와 루트 AGENTS.md를 먼저 읽는다.

## 현재 사용자 경험

송파구 기준의 버리는 방법을 통화하듯 묻고 따라 하는 서비스다. 첫 화면은 `말로 물어보기 / Ask by voice` 카드를 강조한다. 사진 영역의 `사진 찍기 / Take a photo`와 `사진 선택 / Upload a photo`는 같은 크기의 독립 버튼이며 촬영과 앨범·파일 선택을 각각 설명한다. 품목 검색이나 행동별 완료 체크를 기본 절차로 요구하지 않는다.

촬영 입력은 `capture=environment`, 앨범은 별도 파일 입력이다. 데스크톱에서는 촬영도 파일 선택기로 열릴 수 있다. 사진으로 시작하면 마이크 허용·음성 연결 뒤 자동 전송하며 취소·오류 시 대기 사진을 폐기한다. 파일 선택 취소만으로 마이크를 요청하지 않는다.

한국어·영어를 시작 전에 선택한다. 화면·오류·첫인사·전사·음성 답변에 적용하며 연결 중 전환은 잠근다. 종료 후 다시 바꿀 수 있다. 언어는 페이지 메모리에만 유지하고 두 언어 모두 송파구 기준이다.

통화 중 자동 발화 감지·응답·끼어들기, 음소거, 선택형 카메라 정지 화면 공유, 사진 전송, 종료를 제공한다. 전화번호/PSTN/SIP 연결은 없다.

## 코드와 보존할 작업

`src/app/page.tsx`의 기본 화면은 `RecyclingCallApp`이다. 핵심 파일은 이 컴포넌트와 CSS·`call-copy.ts`, `src/lib/client/recycling-call.ts`·`call-images.ts`, `src/lib/contracts/call-language.ts`, `src/lib/server/recycling-call.ts`, `src/app/api/call/route.ts`, `src/data/preparation-guides.ts`다. 자료 흐름은 [architecture](../architecture.md), 언어 헤더 계약은 [contracts](../contracts.md)를 따른다.

이전 PhotoCoach와 API 및 PreparationSummary는 보존한 소비자다. 미사용으로 추정해 삭제하거나 이전 화면을 기본으로 되돌리지 않는다. 기존 단계별 문장 일치 검증을 실시간 생성 음성의 보장으로 설명하지 않는다.

## 유효한 검증 근거

- 최신 UI 코드에서 lint/typecheck/test/build 모두 종료 0, 34파일·572검사 통과.
- Aside 데스크톱과 360×740 CSS iframe의 한국어·영어 화면 확인. 영어 clientWidth=scrollWidth=360, 세 시작 버튼 하단 620px 이내. 가상 대기 마이크로 시작→언어 잠금→취소→복귀 확인.
- 사진 자동 전송·선택 취소·권한 오류·입력 분리와 서버 언어 검증은 자동 검사 및 앞선 가상 브라우저 연결 검사 근거를 재사용한다.
- 실제 OpenAI 연결의 합성 한국어 음성·시험 이미지로 전사·응답·끼어들기·이미지 공유·종료를 확인했다. 별도 준비 텍스트 질문으로 한국어·영어 응답 완료·오디오·전사를 확인했다. 한국어 금지 표현 자동 정규식은 표현 차이로 실패했으나 실제 답변의 절개 금지 안내는 직접 검토했다.
- 과거 정적 산출물의 키 노출 검사는 그 시점의 근거다. 최신 UI 검증이나 합성 입력 성공을 실물 기기·현장 정확도·사람 청취 성공으로 표현하지 않는다.

상세 시점·실패·검증 범위는 [verification](../verification.md)에 보존한다. 문서 정리 중 추가된 배너 피드백도 반영했다. 종료 후 권유 문구와 중복 소개를 제거하고 시작·종료 화면에 같은 제목을 사용한다. 강제 줄바꿈 없이 화면 폭에 맞춘다. 수정 후 네 가지 코드 검사를 다시 통과했다.

## 남은 일

1. 실제 휴대폰에서 신뢰된 HTTPS·촬영/앨범·권한·마이크·스피커·끼어들기·종료를 확인하고 기기/OS/브라우저를 기록한다. 잠금·복귀·네트워크 전환도 미검증이다.
2. 실물의 짧은 안내 품질, 반복 질문, 새 물건 혼입, 불명 성분과 식품용 EPS 보류를 확인한다. 일부 생성 답변은 길이 지침보다 길었으며 정확도·환경 효과는 미측정이다.
3. 학생 직접 작업과 제출용 최종 파일을 확인한다. 학생 기록의 빈칸을 구현자의 작업으로 채우지 않는다. 대회 요건은 기존 확인일의 기록이며 이번에 재조회하지 않았다.

## 실행과 저장소

프로젝트 루트는 이 문서에서 두 단계 위 `WAICY_2026_분리수거AI`다. 기존 `.env`·`.local-https`를 보존하며 비밀값을 출력하지 않는다. [operations](../operations.md)를 따른다. 최근 UI 검증 주소는 `http://localhost:3016`이며 새 세션에서 실행 여부를 다시 확인한다. 개발은 `npm run dev -- --port 3016`, 프로덕션은 build 후 start한다. 다른 작업의 서버를 일괄 종료하지 않는다.

현재 브랜치는 `feat/photo-recycling-coach`다. 기존 통화 구현·UI 개선·이번 문서는 미커밋 작업 트리에 있다. `git remote -v`가 비어 있어 연결된 원격 저장소가 없으며 푸시·공개 배포는 수행하지 않았다. 원격 URL을 추정하거나 새 저장소를 임의 생성하지 않는다. 다음 작업 전 `git status --short`로 기존 변경을 확인하고 보존한다.

HMR에 이전 통화 제어기가 남을 수 있으므로 전송 계약 변경 후 전체 재로드로 새 런타임을 만든다. [engineering-notes](../engineering-notes.md)를 참고한다. 브라우저 QA는 Aside를 사용한다.
