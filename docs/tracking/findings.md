# 아직 확정하지 못한 문제

현재 기본 화면은 통화형이다. 합성 입력으로 실제 WebRTC 연결은 확인했지만 실물 기기·사람 청취·현장 정확도는 미확인이다. 아래 이전 coach의 WAV·부분 결과 기록은 해당 소비자의 근거이며 기본 통화 검증을 대신하지 않는다.

## 식품 포장용 EPS의 송파구 안내 충돌

2026-10-01 확인한 송파구 재활용품 배출 본문은 깨끗한 농·수·축산물 포장 스티로폼의 조건을 안내하지만, 같은 페이지에 연결된 안내서 인쇄 10쪽은 식품 포장용 스티로폼을 종량제 항목에 둔다. 따라서 식품용 EPS에 어느 자료를 우선해야 하는지 확정할 수 없다.

- 본문: https://www.songpa.go.kr/www/contents.do?key=3164
- 연결 안내서: https://www.songpa.go.kr/previewContents.do?atchmnflNo=158114&ems=1fef9fcbf324d25916321108a416213ab3c302e400b4849e8373d46e64841540

영향은 식품용 EPS 확정 안내다. 현재는 해당 부품을 보류하고, 검수된 흰색 비코팅 비식품 생활용품 배송 상자 조건만 안내한다. 원문과 실제 안내서 페이지까지 대조했지만 앱 코드로 기관의 우선 기준을 결정할 수 없으므로 남긴다. 송파구 담당 부서에 적용 대상·최신성·자료 우선순위를 확인한 뒤 근거와 조건을 갱신하는 방법이 있다. 아직 외부 문의는 보내지 않았다.

## 물리 기기의 HTTPS·마이크·화면 미확인

2026-10-08 데스크톱에서 사진·질문·결과와 CSS 폭을 확인하고 CA를 명시한 curl의 localhost/LAN HTTPS도 성공했다. 실제 휴대폰·태블릿에는 접근하지 못해 CA 신뢰 설치·브라우저 HTTPS·카메라·실물 HEIC/EXIF·마이크·재생·가상 키보드·네이티브 확대·OS 동작 줄이기를 확인하지 못했다.

현재 증거는 특정 기기 결함이 있다는 뜻이 아니다. 실제 시연 기기에서 권한·보안 연결·녹음·입력/전송 동작이 막힐 수 있는 범위가 남았다는 뜻이다. 사용할 기기와 소유자가 필요한 신뢰 설정을 확인하고, 기기명·OS·브라우저를 남겨 촬영부터 질문·부분 결과·초기화까지 실행해야 해소된다. HTTP 접속 성공이나 CSS 폭 검사로 닫을 수 없는 항목이다.

## 실제 한국어 음성의 청취 품질 미확인

허용 문장 대조를 통과한 6.6초 Realtime WAV와 브라우저 speaking→idle을 확인했지만 사람이 직접 듣는 검사는 하지 못했다. 생성 음성의 재전사에는 단어 오류가 있었다. 현재 근거만으로 합성 발음 또는 전사 중 어느 쪽의 문제인지 판단할 수 없다.

영향은 사용자가 음성만 듣고 현재 행동을 정확히 이해할 수 있는지다. 실제 청취자·기기 검증이 없으므로 파일과 대응 텍스트 성공만으로 해결 처리하지 않는다. 같은 허용 문장을 사람이 화면과 대조해 듣고 실물 마이크 질문을 함께 검사한 뒤, 발음·전사 오류를 구분해 후속 조치를 정한다. 이전 모델 접근 오류는 후속 실제 요청에서 해소되었으며 현재 접근 불가로 기록하지 않는다.

## 실시간 생성 안내의 검증 범위

기본 통화는 검수 자료를 지침으로 제공하고 곧바로 생성 음성을 재생한다. 기존 coach처럼 전체 출력 문장을 허용 문장과 대조하지 않는다. 합성 아이스팩 사례의 짧은 응답·정정 성공은 모든 범주의 지침 준수나 정확도 보장이 아니다. 실제 물건·불명 조건·위험물·새 물건 전환에서 관찰하고 실패를 재현해 지침 또는 검증 구조의 개선 범위를 정한다. 현재 전화번호/PSTN/SIP 연동은 구현하지 않았다.
