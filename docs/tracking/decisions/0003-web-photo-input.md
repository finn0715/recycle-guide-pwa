# 웹과 파일 촬영·선택으로 시작

상태: 적용. 결정일: 2026-10-01.

핵심 시연은 물건을 인식한 뒤 질문으로 상태를 확인하고 행동을 안내하는 과정이다. 설치된 공용 태블릿은 분실·관리 부담이 있고, 앱 설치나 3D 표현은 이 흐름의 효과를 직접 입증하지 않는다.

Next.js 반응형 웹을 휴대폰·태블릿에서 쓰고 운영체제 파일 촬영·선택을 이용한다. 현재는 PWA 설치·오프라인 기능 없이 신뢰하는 로컬 네트워크에서 시험한다. 지속적인 카메라 스트림은 요구하지 않는다.

네이티브 앱은 기기 연동을 세밀히 다룰 수 있지만 배포·설치 부담이 있다. 키오스크는 배출 장소 접근성을 높일 수 있지만 기기와 현장 운영이 필요하다. 실시간 웹캠은 LAN HTTP의 보안 연결 제약을 더하며 기본 파일 촬영보다 검증 범위가 넓다. 초기에는 이 비용을 들이지 않기로 했다.

설치 없이 핵심 동작을 시연할 수 있지만 OS별 촬영·파일 형식 차이는 남는다. 이 선택은 실기기 검증을 없애지 않으며 오프라인 AI 분석이나 모바일 앱 수준의 카메라 제어를 제공하지 않는다. PWA와 공개 배포 여부는 실제 사용 결과 이후 다시 결정할 수 있다.
