# 0006 — 통화형 대화를 기본으로

날짜: 2026-10-08. 상태: 현재 작업 트리에 적용.

사용자는 품목 검색과 반복 체크를 사용할 수 없는 동선으로 지적했고, 음성만 또는 카메라·사진을 곁들인 지속 대화를 요청했다. 기본 진입을 대화 시작 하나로 바꾸고 통화 중 이미지 공유를 선택하도록 했다. 검색·품목 선택·단계별 완료 체크를 다시 기본 절차로 요구하지 않는다.

WebRTC 실시간 음성·자동 발화 감지·끼어들기를 사용한다. 카메라는 명시적으로 켜며 주기적인 정지 화면을 보낸다. 실제 전화번호로 거는 전화는 별도 미구현 범위다.

검수 자료는 서버 지침으로 제공하나 모델 생성 발화를 기존 coach의 문장 일치 검증으로 제한하지 않는다. 이로 인한 정확도 한계를 명시하고 실제 물건·기기에서 추가로 검증한다. 기존 API 계약과 규칙 원본은 보존한다.

0005는 이전 단계별 소비자의 결정으로 유지한다. 0001의 검수 기준 관리 원칙은 유지하되 기본 통화의 출력 검증 방식은 이 결정으로 구분한다. 코드·실제 연결·화면 검증과 미실시 범위는 [검증 기록](../../verification.md), 후속 작업은 [인수인계](../handoff.md)를 따른다.

## 같은 날 반영한 진입 개선

최초의 단일 시작 버튼에서 음성 우선 카드와 독립된 사진 찍기·사진 선택 버튼으로 개선했다. 사진은 음성 연결 후 자동 전송한다. 한국어·영어 선택은 시작 전에 제공하며 화면·전사·음성에 적용한다. 두 언어 모두 송파구 기준이다. 사진 때문에 음성 진입이 묻히지 않도록 위계를 유지한다.
