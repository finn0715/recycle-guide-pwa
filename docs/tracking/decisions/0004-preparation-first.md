# 0004. 준비 방법을 먼저 보여주는 기본 화면

상태: 당시 결정 이력. 2026-10-08 기본 화면은 사진·단계·음성 안내로 교체되었으며 자유글·음성 질문을 다시 제공한다. 적용 조건과 관찰 사실을 구분하는 원칙은 유지한다.

결정일: 2026-10-01. 사용자가 모바일 화면의 길이, 여러 물건 처리 실패, 반복 확인·제출의 불편을 지적하고 즉시 선택할 수 있는 안내를 요청했다.

기존 흐름은 모든 조건을 확인한 다음 결과를 보여 주어, 사용자가 버리기 전에 해야 할 행동까지 여러 번 확인해야 했다. 기본 화면은 품목 인식과 준비 방법을 분리한다. AI는 사진들에서 지원 품목 목록을 반환하고, 앱은 공식 근거에 연결된 적용 조건·행동 순서·부품별 분류를 보여 준다. 직접 품목을 고르면 모델 호출 없이 같은 방법을 볼 수 있다.

준비 방법의 조건은 사진에서 이미 확인된 사실이 아니다. 예를 들어 “내용물을 다 쓴 플라스틱 샴푸 용기”에 대한 분리·세척 순서를 먼저 알려 주며 사진만 보고 빈 상태라고 판정하지 않는다. 성분에 따라 행동이 달라지는 아이스팩, 기준 충돌이 있는 스티로폼은 짧은 선택을 먼저 받고, 미검수 경우에는 임의 분류를 제공하지 않는다.

사진 선택 버튼에서 분석과 외부 전송을 명시한다. 선택 후 추가 제출을 없애고 여러 품목은 탭으로, 상태 차이는 즉시 바뀌는 버튼으로 다룬다. 긴 예외·출처는 펼침 영역에 넣되 핵심 적용 조건은 계속 표시한다. 기본 화면의 자유글 대화는 제거하고 기존 상세 분석 API와 회귀 검사는 유지한다.

이 결정은 안내 접근성을 개선하지만 숨은 재질·성분을 자동 판별하거나 현장 정확도를 증명하지 않는다. 실제 기기와 폐기물 사례로 수행 시간·사용자 수정·올바른 처리 여부를 추가 평가해야 한다.
