# AI 인식과 배출 기준 분리

상태: 적용. 결정일: 2026-10-01.

2026-10-08에는 같은 분리 원칙을 사진·단계·음성 안내로 확장했다. 새 기본 화면에서 모델은 관찰과 현재 단계의 검수 답을 선택하고 실제 상태 변경은 선택 버튼으로 확인한다. 아래의 발화 근거 검증은 기존 상세 분석 계약에 유지한다.

제품을 알아도 재질·잔여물·복합 부품과 지역에 따라 배출 방법은 달라진다. 사진만으로 내부 상태를 알 수 없는데 모델이 안내까지 생성하면 그럴듯한 오답과 출처가 섞일 수 있다.

모델은 품목·관찰·사용자 확인 사실 후보를 구조화해 반환하고, 서버가 실제 발화와 허용값을 검증한 뒤 정적 검수 기준으로 최종 문구를 구성한다. 불충분한 사실은 질문으로, 근거 충돌과 미검수 조건은 확인 불가로 처리한다.

모델에 배출 방법과 출처까지 생성시키는 방식은 범위를 넓히기 쉽지만 공식 근거를 보장하기 어렵다. 이미지 분류기만 쓰는 방식은 제품 이름 이후의 행동과 숨은 상태를 다루지 못한다. 분석마다 웹 검색하는 방식은 출처·시점·지역 조건의 재현성을 떨어뜨려 현재 소규모 시연에서 선택하지 않았다.

이 결정으로 같은 검수 조건의 배출 문구를 재현할 수 있다. 대신 등록되지 않은 품목·조건의 최종 정답을 모델 지식만으로 제공할 수 없고, 새 지원 범위는 공식 조사·조건 등록·회귀 검사가 필요하다.
