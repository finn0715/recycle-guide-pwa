# 내 사진의 현재 행동과 검수 음성을 함께 안내

상태: 적용. 결정일: 2026-10-08.

이전 기본 화면은 10종 이름을 고른 뒤 고정 준비 설명과 출처를 보여 주었다. 사용자는 자기 사진에서 어느 부분을 어떻게 다룰지 보면서 한 단계씩 진행하고, 막히면 현재 물건과 단계에 맞춰 질문하는 경험을 선택했다.

사진의 실물·부품·위치를 단계와 연결하고 짧은 2D 동작 도해·큰 선택 버튼·AI 음성을 함께 제공한다. 상품 이름 목록보다 재질·용도·부품으로 범주를 넓힌다. 사진·질문 해석과 공식 배출 기준은 분리하며 상태 변경은 사용자 버튼 선택으로 확정한다. 음성 출력은 검수 문장과 대응 텍스트를 대조한 후 재생한다.

고정 설명을 짧게 줄이고 읽어 주는 방식은 사진의 해당 부분과 문제 분기를 해결하지 못한다. 자유 생성 실시간 음성은 현재 단계 밖의 배출 지시가 나올 수 있고 검수 전 재생을 막기 어렵다. 상시 통화·실시간 카메라·3D 대신 짧은 녹음과 요청별 음성 생성을 선택해 입력·취소·외부 전송의 경계를 분명히 한다.

OpenAI로 짧은 녹음을 전송하고 음성 API 비용이 추가되는 사용 방식은 사용자가 선택했다. 앱에는 사진·녹음·대화·진행을 보관하지 않는다. 휴대폰 마이크는 신뢰하는 LAN HTTPS로 사용하며 공개 터널이나 새 인증 서비스를 도입하지 않는다. 기기 CA 신뢰는 필요한 기기에서 수동으로 설정한다.

이 결정으로 물건별 진행과 준비/보류한 부품을 보여 줄 수 있지만 검수하지 않은 조건의 정답·실물 완료·수거 성공을 모델 지식만으로 제공할 수 없다. 음성 파일과 API 연결만으로 휴대폰 마이크나 사람 청취 품질을 보증할 수 없으므로 실제 기기 검사가 별도로 필요하다.
