# AI Showcase 최종 제출 파일

2026-10-08 기준 기본 제품은 한국어·영어 음성 통화와 선택형 카메라·사진 공유다. 첫 화면은 음성을 강조하고 촬영·앨범 입력을 구분한다. 최종 설명·영상은 이 흐름에 맞춘다. 학생 직접 작업·실물 기기·정확도 확인 전에는 완료 실적으로 적지 않는다. 현재 폴더 안내의 제출 요건은 기존 확인 기록이며 이번 문서 정리에서 공식 공지를 재조회하지 않았다.

현재 최종 제출 파일은 없다. 완성하고 검수한 아래 네 파일을 이 폴더에 모은 뒤 Google Drive에 올린다. 작성 초안과 접수 연락처 문서는 업로드하지 않는다.

## 폴더명

`Main_Category_ProjectName`

- Category: Elementary, Middle, High 중 확인한 부문
- ProjectName: 확정한 영문 프로젝트명
- 예시: `Main_Elementary_RecycleGuide`는 이름 형식의 예시이며 태건이의 참가 Category를 확정한 것이 아니다.

## 필수 파일

1. `Main_Category_ProjectName_Presentation.pdf` — 완성한 발표 슬라이드
2. `Main_Category_ProjectName_Description.pdf` — 프로젝트명, Project Description, AI Usage Explanation
3. `Main_Category_ProjectName_PresentationVideo.mp4` — 최대 3분 발표
4. `Main_Category_ProjectName_DemoVideo.mp4` — 최대 3분 시연

`Category`와 `ProjectName`은 그대로 남겨 두지 않고 실제 값으로 바꾼다. 추가 자료는 선택 사항이며 `Main_Category_ProjectName_AdditionalMaterials`로 구분한다.

## 마지막 확인

- [ ] 두 PDF에 작성 안내·빈칸·계획 단계의 미확정 표현이 남지 않았다.
- [ ] 실제 구현과 근거에 맞는 설명이다.
- [ ] 두 영상이 각각 3분 이하이며 영어 또는 영어 자막을 포함한다.
- [ ] 파일을 모두 열어 확인했다.
- [ ] 로그인하지 않고 Drive 폴더를 열어 접근을 확인했다.
- [ ] 공식 온라인 폼에 최종 폴더 링크를 입력하고 제출 완료를 확인했다.
