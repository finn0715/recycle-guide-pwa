# WAICY 2026 분리수거 AI 제출 준비

**Sites PWA 현재 운영:** 설치·배포 소스, 접근 범위, Workers 통화 종료 계약과 검증은 [Sites PWA](docs/sites-pwa.md)를 우선 따른다. 아래 Next 로컬 서버 기록과 구분한다.

새 세션은 [인수인계](docs/tracking/handoff.md)부터 읽는다. 현재 기본 UX는 통화형 대화이며 이전 단계별 화면의 기록은 이력으로 보존한다.

송태건의 분리수거 AI 프로젝트를 만들면서 기록하고, AI Showcase 제출물로 정리하기 위한 작업 폴더다. 공식 양식이 아닌 개인 작업 문서다. 현재는 송파구 가정용 분리배출 안내 웹앱을 구현했으며, 제출물은 실제 검증 결과에 맞춰 작성하는 단계다.

## 현재 결정 사항

- 참가 부문: AI Showcase Track
- 프로젝트 방향: 통화처럼 말로 묻고 답을 들으며 필요할 때 카메라·사진으로 물건을 보여주는 분리배출 안내
- 영문 프로젝트명: RecycleGuide를 임시로 사용하며 최종 이름은 미정
- 구현: 한국어·영어 Next.js 웹앱, 휴대폰·태블릿 화면 대응, 송파구 기준 고정
- AI: 기본 통화는 OpenAI `gpt-realtime-2.1-mini`를 WebRTC로 연결. 이전 사진 인식·단계별 안내 API는 별도 유지
- 배출 안내: 검색·품목 선택·완료 체크 없이 말로 질문. 검수된 준비 자료를 바탕으로 짧게 답하며 불명 조건은 대화로 확인
- 범위: 송파구 일상 안내 13범주와 배터리·전자제품·대형·위험물의 공식 수거/문의 4범주. 낯선 상품명도 재질·용도·부품으로 확인
- 시작 화면: `말로 물어보기 / Ask by voice`를 우선 표시. `사진 찍기 / Take a photo`와 `사진 선택 / Upload a photo`는 독립 버튼으로 구분
- 언어: 시작 전 한국어·영어 선택. 화면·오류·전사·음성 답변에 적용하며 연결 중에는 변경 불가. 지역은 두 언어 모두 송파구
- 음성: 연결 뒤 자동 발화 감지·응답·끼어들기. 카메라는 켠 동안 약 3초마다 화면을 전달하고 사진 전송도 지원. 앱은 대화·사진을 저장하지 않음
- 검증: 현재 통화형 검증은 `docs/verification.md` 참고. 실제 서비스에 합성 음성·시험 이미지로 연결 확인. 실물 폐기물 정확도·환경 효과·휴대폰 마이크·사람 청취 품질은 미확인
- 초등 또는 중등 등 최종 참가 Category: 확인 필요

## 빠른 실행

확인한 개발 환경은 Node.js 22.22.3, npm 10.9.8이다. 아래 명령은 이 폴더에서 실행한다.

```sh
npm ci
# .env가 없는 경우에만 예제를 만든다. 기존 키 설정은 보존한다.
if [ ! -f .env ]; then cp .env.example .env; fi
```

`.env`의 `OPENAI_API_KEY`에 사용할 키를 로컬 편집기로 설정한다. 이미 설정되어 있으면 그대로 사용한다. 키를 화면·로그·문서에 출력하거나 저장소에 커밋하지 않는다. 예제 환경변수는 `OPENAI_API_KEY` 하나이며 모델은 서버 코드에 고정되어 있다.

```sh
npm run dev
```

컴퓨터에서 `http://localhost:3000`을 열고 언어를 선택한 뒤 ‘말로 물어보기’를 눌러 마이크 권한을 허용한다. 바로 말로 질문하고 답을 듣는다. 사진으로 시작하려면 ‘사진 찍기’ 또는 ‘사진 선택’을 사용한다. 선택한 사진은 마이크를 허용하고 연결된 뒤 자동 전송된다. 데스크톱에서는 촬영 버튼도 파일 선택기로 열릴 수 있다. 필요할 때 통화 중 카메라를 켜거나 사진을 보낸다. 품목 검색·완료 체크는 없다. 브라우저 통화이며 전화번호로 거는 전화는 아니다.

휴대폰 마이크에는 신뢰하는 HTTPS가 필요하다. OpenSSL 3가 설치되어 있으면 다음 명령으로 로컬 인증서와 별도 개발 서버를 준비한다.

```sh
npm run https:prepare
npm run dev:https -- --port 3443
```

같은 Wi-Fi의 휴대폰은 출력된 컴퓨터 LAN 주소로 접속한다. CA 공개 인증서를 기기에 직접 신뢰시키는 마지막 절차가 필요하며 개인키·`.env`는 공유하지 않는다. [로컬 실행 절차](docs/operations.md)에 구체적인 설정·종료 방법이 있다. 공개 터널·공개 배포는 사용하지 않는다. 현재 TLS와 앱 HTML은 CA를 명시한 curl로 확인했지만 OS·휴대폰 신뢰 설치와 실물 마이크는 미실시다.

[실행·검증 기록](docs/verification.md)에는 2026-10-08 결과와 이전 이력이 구분되어 있다. 준비 자료의 성공을 학생 직접 수행 실적이나 현장 정확도로 바꾸어 적지 않는다.

코드 검증 명령은 다음 네 가지다. 빌드 성공만으로 실물 기기 동작이나 AI 정확도가 검증되지는 않는다.

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

2. [설명서 초안](02_설명서초안.md)을 실제로 구현한 내용에 맞춰 고친다.

5. [최종 제출 폴더](최종제출/README.md)에 검수한 PDF 2개와 MP4 2개를 모은다.

## 공식 제출 요건

2026년 10월 1일 확인한 공식 가이드북 5~7쪽 및 온라인 제출 폼 기준이다.

| 제출 위치 | 항목 | 요건 |
|---|---|---|
| 온라인 폼 | 프로젝트 요약 | 200단어 이하 |
| 설명서 PDF | Project Description | 최대 250단어 |
| 설명서 PDF | AI Usage Explanation | 최대 250단어, 사용 AI·AI 역할·학생의 직접 제작 부분 설명 |
| 발표자료 PDF | Presentation | 발표에 쓰는 자료, 슬라이드 수나 고정 레이아웃은 안내되지 않음 |
| 발표 영상 MP4 | Presentation Video | 최대 3분 |
| 시연 영상 MP4 | Demo Video | 최대 3분, 시뮬레이션도 허용 |

프로젝트 설명을 200단어 이내로 작성하면 온라인 요약과 PDF 설명에 재사용할 수 있다. AI 활용 설명은 별도 항목이다.

두 영상 모두 영어로 말하거나 영어 자막을 넣는다. 영어로 말하는 영상의 자막은 선택 사항이다. 가이드북 5쪽은 총 6분 구성을 설명하고, 6쪽은 발표와 시연을 별도 영상 파일로 지정한다.

Google Drive에 제출 파일을 넣고, 심사위원이 접근할 수 있도록 공유한 폴더 링크를 온라인 폼에 입력한다. 팀당 한 번 제출하며, 지역 공식 주최자를 통한 참가자는 해당 주최자의 안내를 확인한다.

## 일정

| 항목 | 공식 일정 |
|---|---|
| 제출 마감 | 2026년 11월 29일 오후 5시 EST, 한국시간 11월 30일 오전 7시 |
| 본선 시간 배정 | 12월 2일 |
| 본선 | 12월 4~6일, 온라인·현장 병행 |
| 수상 발표 | 12월 7일 |

본선 구성은 발표 3분, 시연 3분, 질의응답 4분이다. 사전 코칭과 발표 중 통역은 허용된다. 실시간 참석을 권장하며, 불참자는 원칙적으로 질의응답 점수를 받지 못하고 별도 조정 가능 여부는 주최자에게 확인한다.

가이드북 일부에 2025년과 이전 날짜가 남아 있다. 이 표는 표지·3~4쪽 일정 및 현재 제출 폼을 근거로 정리했으며, 본선 참여 시간은 추후 배정 안내를 따른다.

## 개발 중 확보할 근거

- 학생이 직접 겪거나 관찰한 분리배출의 어려움
- 대화 시작부터 음성 질문·선택 이미지 공유·응답·종료까지 보이는 실제 화면
- AI가 하는 판단과 미리 정한 규칙이 하는 일을 구분한 설명
- 맞힌 사례, 틀린 사례, 모르는 물건을 처리한 사례
- 학생이 직접 설계·코딩·학습·조사·테스트한 내용
- 분리배출 안내에 사용한 공식 기준의 출처와 적용 지역

사진만으로 보이지 않는 재질이나 오염 상태를 확정하지 않는다. 사용자의 추가 확인, 분류 수정, 공식 기준 확인 등의 처리 방식은 구현 범위에 맞춰 정한다. 성능이나 환경 효과는 실제 측정한 결과만 적는다.

## 제출 전 확인

- [ ] 프로젝트명과 Category를 확정했다.
- [ ] 설명서·슬라이드·영상·폼의 내용이 서로 일치한다.
- [ ] 계획했던 기능과 실제 구현한 기능을 구분했다.
- [ ] 학생의 직접 제작 부분과 사용 도구를 정확히 적었다.
- [ ] 영문 단어 수를 최종 확인했다.
- [ ] 두 영상이 각각 3분 이하이며 영어 또는 영어 자막을 포함한다.
- [ ] PDF 2개가 열리고, 영상 2개가 끝까지 재생된다.
- [ ] 파일명과 Drive 폴더명이 가이드북 규칙에 맞는다.
- [ ] Drive 링크를 로그인하지 않은 상태에서 열어 접근을 확인했다.
- [ ] 최신 공지와 제출 폼을 다시 확인했다.
- [ ] 제출 완료 안내를 확인하고 접수 증빙을 보관했다.
